Vertex AI Platform

An enterprise-grade AI chat widget that any business can embed on their website with a single line of code.

Quick Start

Add this single script tag to your website to embed the chat widget:

<script src="dist/vertex-widget.js"
  data-tenant-slug="demo-clinic"
  data-primary-color="#6366f1"
  data-position="bottom-right"></script>

Configuration

Customize the widget using data attributes on the script tag:

data-tenant-slug     — Your business slug (required)
data-primary-color  — Brand color, e.g. #6366f1
data-position      — bottom-right or bottom-left
data-api-base-url  — API server URL (default: same origin)
data-ws-base-url   — WebSocket server URL (auto-derived)

Programmatic API

Control the widget from your JavaScript code:

// Open the chat panel
window.vertexWidget.open();

// Close the chat panel
window.vertexWidget.close();

// Remove the widget entirely
window.vertexWidget.destroy();

Click the chat bubble in the bottom-right corner to try it out.
